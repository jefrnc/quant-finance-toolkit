# Quant Finance Toolkit

A collection of interactive web tools for personal financial planning and trading productivity. Built with vanilla HTML/CSS/JS — no dependencies, runs entirely in the browser.

## Tools

### Financial Planning
| Tool | Description |
|---|---|
| [Cash Flow Analysis](cashflow.html) | Track income, expenses, and cash flow projections |
| [Define Your Dream](define-your-dream.html) | Goal-setting framework for financial objectives |
| [Your Dream in Figures](your-dream-in-figures.html) | Convert financial goals into actionable numbers |
| [Financial Stability Check](your-financial-stability.html) | Assess your current financial health |
| [Self Diagnosis](self-diagnosis.html) | Financial habits and risk profile evaluation |

### Trading
| Tool | Description |
|---|---|
| [DAS Trader Hotkeys Guide](das-trader-hotkeys-guide.md) | Complete hotkey reference for DAS Trader Pro |

## Usage

Open any `.html` file directly in your browser, or visit the hosted version.

All calculations run client-side — no data is sent to any server.
